# Mangalam HDPE Pipes Landing Page

A responsive single-page product landing page built with HTML, CSS, and JavaScript.

## Overview

This repository contains a static marketing page for a premium HDPE pipe product, including:

- hero section with product details and CTA buttons
- scrolling brand marquee
- technical specifications table
- downloadable datasheet modal
- interactive product image magnifier

## File Structure

- `index.html` — main page markup
- `styles/` — page styling and layout rules
- `script.js` — page interactivity and UI behavior
- `assets/` — images, icons, and branding assets

## Features

- sticky header with hide-on-scroll behavior
- modal popup for datasheet download
- form validation for email and phone input
- image zoom/magnifier effect on hover
- accessible structure with ARIA attributes for the modal

## Usage

Open `index.html` directly in a browser to view the page.
